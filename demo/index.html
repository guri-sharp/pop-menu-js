Lightweight popup & context menu library

メニューの動きとコードを、
並べて確かめる。

右クリック、クリック、長押し。ポップオーバーからボトムシート、サイドドロワーまで。 すべてのサンプルは左のプレビューで動き、右に表示されたコードがそのまま実行されています。

サンプルを見る GitHub
npm install pop-menu-js
  • 依存パッケージなし
  • 3 つの起動トリガー
  • シート & ドロワー
  • WAI-ARIA 対応
01

基本のトリガー

右クリック、クリック、長押し、手動制御。起動方法をひとつ選ぶだけです。

02

クリックで開くボタンメニュー

要素を基準に配置し、同じボタンで開閉。画面端では自動で位置を反転します。

click / anchor
プレビュー クリック

もう一度押すと閉じます（toggle）。画面端では自動で反転します。

                  new PopMenu('#ex-click', {
                    trigger: 'click',
                    anchor: 'element',
                    placement: 'bottom-start',
                    offset: { x: 0, y: 8 },
                    toggle: true,
                    items: [
                      { label: '新規ドキュメント', icon: 'fa-solid fa-file-circle-plus',
                        onClick: () => log('新規ドキュメント') },
                      { label: 'フォルダを開く', icon: 'fa-solid fa-folder-open',
                        onClick: () => log('フォルダを開く') },
                      { label: 'エクスポート', icon: 'fa-solid fa-file-export',
                        onClick: () => log('エクスポート') }
                    ]
                  });
03

モバイルの長押し（Long press）

タッチ端末で押し続けるとメニューを表示します。移動したらキャンセル、対応端末では振動も。

longpress
プレビュー 500ms 長押し

マウスでは動作しません。DevTools のデバイスモードでも試せます。

                  new PopMenu('#ex-longpress', {
                    trigger: 'longpress',
                    longPressDuration: 500,      // 長押し成立までの時間
                    longPressMoveTolerance: 10,  // 10px 動いたらキャンセル
                    haptic: true,                // 対応端末では振動
                    items: [
                      { label: 'ピン留め', icon: 'fa-solid fa-thumbtack',
                        onClick: () => log('ピン留め') },
                      { label: '返信', icon: 'fa-solid fa-reply',
                        onClick: () => log('返信') },
                      { divider: true },
                      { label: '非表示にする', icon: 'fa-solid fa-eye-slash',
                        danger: true, onClick: () => log('非表示') }
                    ]
                  });
04

1 つのインスタンスを複数の行で共有

手動トリガーと setTarget() で、表示位置だけを行ごとに切り替えます。

manual / setTarget
プレビュー 「…」をクリック
請求書_2026.pdf
キービジュアル.png
議事録_第12回.md

メニュー本体は 1 つだけ。行ごとに作り直す必要はありません。

                  const rowMenu = new PopMenu('.js-row-action', {
                    trigger: 'manual',
                    anchor: 'element',
                    placement: 'bottom-end',
                    items: [
                      { label: '複製', icon: 'fa-solid fa-copy',
                        onClick: () => log('複製') },
                      { label: '名前を変更', icon: 'fa-solid fa-pen',
                        onClick: () => log('名前を変更') },
                      { divider: true },
                      { label: '削除', icon: 'fa-solid fa-trash', danger: true,
                        onClick: () => log('削除') }
                    ]
                  });

                  document.querySelectorAll('.js-row-action').forEach(button => {
                    button.addEventListener('click', () => {
                      rowMenu.setTarget(button);
                      rowMenu.show();
                    });
                  });

カスタム枠と吹き出し

customContent に任意の HTML を渡せます。フォームやピッカーもこの通り。

customContent
プレビュー クリック

カスタム枠 + 吹き出し。中身は自由な HTML です。

                  new PopMenu('#ex-picker', {
                    trigger: 'click',
                    anchor: 'element',
                    placement: 'bottom',
                    arrow: true,
                    customContent: `
                      <div class="demo-picker">
                        <strong>色を選択</strong>
                        <div class="demo-swatches">
                          <button style="--c:#ef4444" onclick="log('赤')"></button>
                          <button style="--c:#10b981" onclick="log('緑')"></button>
                          <button style="--c:#3b82f6" onclick="log('青')"></button>
                          <button style="--c:#f59e0b" onclick="log('黄')"></button>
                        </div>
                        <small>任意の HTML を埋め込めます</small>
                      </div>
                    `
                  });

09

チェック項目・ラジオ項目・グループ

setItems() で表示中の項目を更新。フォーカスは同じ id の項目に保たれます。

menuitemcheckbox
プレビュー クリック

項目を選んでも閉じず、チェック状態をその場で更新します。

                  let compact = true;
                  let sort = 'name';

                  const buildItems = () => [
                    { group: '表示' },
                    { id: 'compact', label: 'コンパクト表示',
                      role: 'menuitemcheckbox', checked: compact,
                      onClick: () => { compact = !compact; menu.setItems(buildItems()); } },
                    { divider: true },
                    { group: '並び順' },
                    { id: 'sort-name', label: '名前順',
                      role: 'menuitemradio', checked: sort === 'name',
                      onClick: () => { sort = 'name'; menu.setItems(buildItems()); } },
                    { id: 'sort-date', label: '日付順',
                      role: 'menuitemradio', checked: sort === 'date',
                      onClick: () => { sort = 'date'; menu.setItems(buildItems()); } }
                  ];

                  const menu = new PopMenu('#ex-check', {
                    trigger: 'click',
                    anchor: 'element',
                    closeOnSelect: false,
                    items: buildItems()
                  });
10

メニュー内のリンクとボタン

element 項目なら、通常のリンクやフォームの動作をそのまま保てます。

item.element
プレビュー クリック

リンクはリンクとして、ボタンはボタンとして動きます。

                  const link = document.createElement('a');
                  link.href = 'https://github.com/guri-sharp/pop-context#readme';
                  link.target = '_blank';
                  link.rel = 'noopener';
                  link.textContent = '利用規約を開く';

                  const notify = document.createElement('button');
                  notify.type = 'button';
                  notify.textContent = '通知を確認';
                  notify.addEventListener('click', () => log('通知を確認しました'));

                  new PopMenu('#ex-elements', {
                    trigger: 'click',
                    anchor: 'element',
                    items: [
                      { id: 'terms', element: link },
                      { id: 'notify', element: notify }
                    ]
                  });

データ属性から自動初期化

HTML の data-pop-menu と <template> だけでメニューを定義できます。

autoInit
プレビュー クリック

JS 側は PopMenu.autoInit() を呼ぶだけです。

                  <button data-pop-menu
                          data-pop-menu-items="#ex-actions-template">
                    宣言的メニュー
                  </button>

                  <template id="ex-actions-template">
                    <div data-pop-item>
                      <span data-pop-label>編集</span>
                    </div>
                    <div data-pop-item>
                      <span data-pop-label>複製</span>
                    </div>
                    <div data-pop-item data-pop-divider></div>
                    <div data-pop-item data-pop-disabled="true">
                      <span data-pop-label>利用できません</span>
                    </div>
                  </template>
                
                  PopMenu.autoInit(document);

14

カスタム内容のリッチなシート

関数を渡せば、シートの中身を DOM で組み立てられます。this.hide() も使えます。

customContent / sheet
プレビュー クリック
このページをシェア customContent でリッチなシートを構築 
                  new PopMenu('#ex-share', {
                    trigger: 'click',
                    presentation: 'sheet',
                    detents: ['half', 'full'],
                    defaultDetent: 'half',
                    ariaLabel: 'このページを共有',
                    customContent(container) {
                      const content = document.createElement('section');
                      content.className = 'demo-share';
                      content.innerHTML = `
                        <div class="demo-share-head">
                          <span class="demo-share-icon">
                            <i class="fa-solid fa-arrow-up-from-bracket"></i>
                          </span>
                          <div>
                            <span class="demo-share-eyebrow">SHARE</span>
                            <h3>このページを共有</h3>
                          </div>
                          <button class="demo-share-close" type="button"
                                  aria-label="閉じる">
                            <i class="fa-solid fa-xmark"></i>
                          </button>
                        </div>
                        <p class="demo-share-desc">
                          共有方法を選択してください。
                        </p>
                        <div class="demo-share-actions"></div>
                      `;

                      content.querySelector('.demo-share-close')
                        .addEventListener('click', () => {
                          this.hide({ restoreFocus: true });
                        });

                      ['リンクをコピー', 'メッセージ', 'メール'].forEach(label => {
                        const button = document.createElement('button');
                        button.type = 'button';
                        button.textContent = label;
                        button.addEventListener('click', () => {
                          log(label);
                          this.hide({ restoreFocus: true });
                        });
                        content.querySelector('.demo-share-actions')
                          .appendChild(button);
                      });

                      container.appendChild(content);
                    }
                  });
05

セットアップ

npm または 2 つのファイルを読み込むだけで使い始められます。

npm でインストール

              npm install pop-menu-js

ファイルを読み込む

              <link rel="stylesheet"
                    href="node_modules/pop-menu-js/src/pop-menu.css">
              <script src="node_modules/pop-menu-js/src/pop-menu.js"></script>

最小構成のクイックスタート

              new PopMenu('#menu-button', {
                trigger: 'click',
                items: [
                  { label: '編集', onClick: () => console.log('edit') },
                  { label: '削除', danger: true, onClick: () => console.log('delete') }
                ]
              });

このページのサンプルは、右側に表示されているコードをそのまま実行しています。 log() はデモ用の通知ヘルパーです。実際のコードでは任意の処理に置き換えてください。
